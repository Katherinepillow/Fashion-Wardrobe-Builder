# still. — wardrobe studio

A static, browser-only fashion moodboard. Open index.html in a modern browser, or run a local static server in this directory. The 25 wardrobe images are stored in images/ and the collection is defined near the top of app.js.

Select pieces, drag and resize them on the canvas, name the look, and save it in browser local storage. Saved looks stay in the same browser. The collection was replaced, so outfits saved using the earlier placeholder items will no longer display those removed items.

The supplied images retain their original backgrounds and are included for local preview. Verify rights to publish the supplied product photos before deploying publicly.
